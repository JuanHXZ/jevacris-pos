# Workflow: implement-screen

Uso: /implement-screen <nombre de la pantalla>

1. Activa el skill ui-implementer
2. Busca la pantalla en docs/design/screens-inventory.md (o el índice
   equivalente)
3. Trae el diseño de esa pantalla desde la herramienta de diseño conectada
4. Presenta la propuesta de componentes (nombres, responsabilidad, props,
   reutilización) y espera aprobación del usuario — NO generar código todavía
5. Una vez aprobado, genera el componente correspondiente
6. Si hay forma de verificar visualmente el resultado contra el diseño
   original, hazlo y ajusta
7. Reporta qué componentes compartidos se crearon/reutilizaron
